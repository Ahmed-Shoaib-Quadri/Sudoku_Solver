# Sudoku Solver
<p>The application is built using Java, Java AWT and Java Swing.<br>
In order to run the application in the system, clone all the files into a folder using the command : <br><code>git clone</code><br><br>
Then open the terminal, locate to the folder where the files are saved and then run the command : <br><code>javac *.java</code><br><br>
Lastly, run the application by running the command in the terminal : <br><code>java SudokuMain</code><br><br>
Enjoy testing the application with various inputs!</p><br>
<p>There is a test file present, named as <b>Benchmark.java</b> which compares the traditional Backtracking Algorithm
  with the DeepBlue's Algorithm X + Dancing Links a.k.a DLX and provides a comparitive report on it. You can check it out by running the command : <code>java Benchmark</code>.</p>
